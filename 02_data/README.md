# Manifest files linking to the data

Manifest files are here, in CSV format, for genomics and transcriptomics separately.  

G means Genomics, T means Transcriptomics.  

* First column is the sample ID.  
* Second column is the R1 download link.  
* Third column is the R2 download link.

If any link is failed, you can inform the corresponding author.  
Use `wget -c` to download files.
